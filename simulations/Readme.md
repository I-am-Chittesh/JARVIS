# Patent Simulation Demonstration

This folder contains three videos, each explaining a specific part of the system architecture:

* **Video 1: `jarvis_auth.py` (The Daemon)** - Demonstrates the background service physically blocking distracting websites and syncing media controls.
* **Video 2: `hardware_sim` (Simulation)** - Shows the desktop interface and electronics simulation using wokwi.
* **Video 3: `cam_ui.py` (Optical Pipeline)** - Proves the screenless camera module works by compressing an image to the exact 240x320 hardware display size and logging it to a local database.
